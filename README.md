# Sheep-and-wolves
Game describtion and rules:

"Sheep and Wolves"  is a traditional board game of checkers for two players. One player has one white checker (the "sheep"), and the other has four black checkers (the "wolves").

The game is played on a chessboard (only on dark squares). Checkers can move diagonally to the nearest unoccupied square—wolves can only move forward, sheep can only move forward and backward. At the beginning of the game, the sheep and wolves are positioned opposite each other at the edges of the board, with the sheep moving first.

The sheep's goal is to reach the opposite edge of the board, at which point it wins the game. The wolves win if they manage to surround the sheep or pin it to the edge so it can't move any further.
